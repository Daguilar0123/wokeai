# Lockup

The mark beside the name with the pronunciation line beneath: the brand's one complete sentence. Horizontal for page headers and OG images; stacked for square avatars.

Horizontal: mark at 72px, `wordmark` style, then `caption` style in `muted` on the second line, 18px gap between mark and text. Stacked: mark centered above the name with a `space-3` gap; drop the pronunciation line below 160px total height. The mark inherits `ink`; on an `accent` avatar set it in `surface`. The consumer provides the surface; the lockup never draws its own background.
