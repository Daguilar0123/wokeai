# Button

Two buttons and a link. Primary is `accent` fill with `accent-ink` text, 600 weight, `radius-md`, 12px by 20px padding; one per screen. Quiet is `ink` text on `card` with a 1px `rule` border, same shape. Links in running text are `accent`, underlined 1px with a 2px offset, never bold. Focus is a 2px `accent` outline offset 2px; the consumer must not remove it. Labels say what happens ("Join", "Add a tool"), never "Submit".
