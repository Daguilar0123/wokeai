# Wordmark

The name as type, in two forms. The primary is `wokeai`, lowercase, `wordmark` style, tracking −0.03em; it is the brand on every surface. The secondary is `wōke•ĀĪ`, the pronunciation line turned into a dictionary-entry wordmark, for social headers, merch, and the podcast lockup; it needs real Ā, Ī, ō glyphs and an interpunct in Archivo, so check them before shipping. Both are set in `ink` on `surface` or `card`, or `surface` on `accent`. Never set the name in title case, never add a period, never put it in quotation marks.
