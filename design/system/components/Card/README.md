# Card

The one raised surface on the site: `card` fill, 1px `rule` border, `radius-md`, `space-4` padding. Two uses. The tool card holds a link in `accent` (600 weight) and one line of `small` text in `muted` describing what the tool does; cards stack with a `space-3` gap. The pillar card holds a bold one-word title in `ink` and one sentence in `muted`; three sit in a row on desktop and stack on phones. No shadow, no accent bar, no icon. The consumer provides the list; the card never fetches anything.
